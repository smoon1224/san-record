# 산 기록

구매 날짜, 쇼핑몰, 구매 수단, 금액, 물품을 기록하는 개인용 구매 장부입니다.

## 기능

- 구매 기록 추가, 수정, 삭제
- 쇼핑몰과 카드/구매 수단 목록 추가, 수정, 삭제
- 월별 필터와 물품·쇼핑몰 검색
- 구매 기록 CSV 내보내기
- 브라우저 `localStorage`에 자동 저장

## 실행

`index.html`을 브라우저에서 열면 됩니다. 별도 설치나 서버가 필요하지 않습니다.

## 데이터 저장

기록은 현재 브라우저에만 저장됩니다. 다른 브라우저나 기기와 자동 동기화되지 않으며 브라우저 데이터를 삭제하면 기록도 지워질 수 있습니다. 필요한 기록은 CSV로 내보내 보관하세요.

## GitHub Pages

GitHub Pages는 정적 웹사이트를 호스팅합니다. 사이트 파일은 공개 저장소에 올라가므로 개인정보나 구매 내역을 파일에 넣지 마세요. 구매 기록은 각 방문자의 브라우저에 따로 저장됩니다.
